# 黄昏血族 · 血誓牌局

直接双击 **启动游戏.command**（macOS）、**启动游戏.bat**（Windows）或 **启动游戏.sh**（Linux），也可以直接双击 **index.html**。整个游戏离线运行，不需要安装、服务器或账户。请让 game.js、game.css、media 文件夹与 index.html 留在同一个文件夹里。

## 一分钟上手

1. 在夜之馆选择六名血族之一和 AI 难度（新血 / 标准 / 深谋），点击「进入黄昏」。一名玩家对战五名 AI，对手座次每局随机。
2. 你的回合有 3 个行动点。**点一张手牌**，可选的目标会亮起，**直接点击目标**就会出牌；不需要目标的牌再点一次（或按「使用」）即可打出。
3. 也可以发动角色技能、点燃遗骸之灯、在血誓之柱立誓、强化血脉。点「结束回合」交给下一名血族。
4. 遭到攻击时会弹出响应：选择「夜行」「震慑之啸」等响应牌，或「承受伤害」。没有倒计时。
5. 拿不定主意时点「低语」（或按 H）：它会用最强 AI 的眼光给出一条建议，并高亮对应的牌与目标。

## 胜利条件

- **第 5 轮开始时**，只保留美德前 5 名；**第 7 轮开始时**，只保留前 3 名进入月血决战。右侧排名中的红色「筛选线」随时告诉你离危险有多近。
- 决战中每人两条生命，最后存活者获胜。若到第 14 轮仍未分胜负，按「生命 ×20 + 体力 + 美德」裁决。
- 排名依次比较美德、体力、血晶、击倒数。

## 美德从哪里来

| 来源 | 收益 |
| --- | --- |
| 点燃遗骸之灯 | 每回合一次：+1 美德、+1 血晶、摸 1 张牌 |
| 狩猎游荡强敌 | 对中央强敌造成最后一击：+1~4 美德与战利品 |
| 血誓之柱（第 3–6 轮） | 立誓 +1 美德；守到自己的下个回合开始再 +2。只有美德**不高于**持誓者的血族才能覆写，盟友的誓言不可覆写 |
| 击倒血族 | +3 美德、+2 血晶、摸 1 张牌；首次击倒自己的宿敌再 +3 |
| 暂时同盟 | 结盟者 +1 美德，双方各摸 1 张 |

决战前倒下会满血重生，但失去 2 美德。

## 回合规则

- 第 1 轮由你先行动；此后每轮按美德从高到低依次行动——领先者先手，落后者压轴，同分时按每轮轮换的座次。座位旁会显示本轮的行动顺位。
- 回合开始摸 2 张牌、获得 1 血晶，3 个行动点。每回合限 1 张「血袭」、1 次技能。
- **吸血**：每回合首次伤害其他血族时 +1 血晶。
- 血袭受攻击距离限制（座位环形距离）；技能与谋略无视距离。
- 强化血脉每次 3 血晶：一级血袭伤害 +1，二级技能消耗 −1。
- 回合结束自动弃牌至体力值（至少 3 张），优先保留治疗、防御与血袭。

## 月血决战（第 7 轮起）

- 同盟与血誓解散，三人满血、各有两条生命，立即补给 3 张牌与 3 血晶；每 10 美德额外 +1 体力上限（最多 +2）。
- 每回合 5 行动点、摸 4 张牌、+2 血晶；技能 2 次、基础血袭 2 次（武器再 +1）；留牌上限为体力 +2（至少 5 张）。
- 燃尽一条生命后，以半数体力 +1 重返战场。
- 第 9 轮起「血月狂潮」：所有攻击伤害 +1。

## 快捷键

数字 1–9 选牌 · S 技能 · L 点灯 · P 立誓 · U 强化 · H 低语 · E 结束回合 · Esc 取消。响应时：数字键打出响应牌，T 承受伤害。

## 保存进度

游戏自动保存到当前浏览器，回到夜之馆点击「继续第 N 轮」即可。暂停菜单可导出、导入 JSON 存档，也能调整 AI 速度、开关音效、重看玩法速览。旧版本（v0.2）的存档可以直接导入。私密浏览或禁止本地存储时，请用导出存档迁移进度。

你被筛除或在决战中倒下后，可以选择「观战至终局」看完这场血宴。
