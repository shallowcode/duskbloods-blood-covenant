# 黄昏血族 · 血誓牌局

直接双击 **启动游戏.command**（macOS），或双击 **index.html** 即可开始。Windows 使用 **启动游戏.bat**，Linux 使用 **启动游戏.sh**。整个游戏离线运行，不需要安装依赖、启动服务器或登录账户。请将 game.js、game.css、media 文件夹和 index.html 放在同一个游戏文件夹中。

## 怎样开始

1. 在夜之馆选择六名血族之一，点击「进入黄昏」。一名玩家对战五名 AI。
2. 你的回合有 3 个行动点，最终三人阶段增加至 5 个。点击手牌查看效果；攻击牌再点击一名敌人或中央强敌，然后点「确认出牌」。
3. 也可发动角色技能、点燃遗骸、覆写血誓或强化血脉。点击「结束回合」交给下一名血族。
4. 遭到攻击时会暂停牌局，选择「夜行」「震慑之啸」等响应牌，或点击「承受伤害」。响应没有倒计时。

## 胜利条件

- 第 1–2 轮：狩猎和点灯，积累美德、血晶和装备。
- 第 3–4 轮：血誓之柱开启。花 1 血晶覆写誓言可获得 2 美德，前任失去相应美德。
- 第 5–6 轮：按美德筛至 5 人。
- 第 7 轮起：美德前三进入最终决战，同盟解散，满血并获得两次生命，最后存活者胜利。
- 决战补给：入场额外摸 3 张牌、获得 3 血晶；每回合 5 行动点、摸 4 张牌、获得 2 血晶（上限 9）。技能每回合最多 2 次，逐次支付消耗；血袭基础上限 2 次，武器再 +1。留牌上限为体力 +2，至少 5 张。
- 第 9 轮起「血袭」额外 +1 伤害；第 14 轮若尚无胜者，按剩余生命 ×20 + 体力 + 美德裁决。

前期阵亡可以重生，但失去 2 美德。击倒血族获得 3 美德；首次击倒指定宿敌，额外获得 3 美德。美德同分时比较体力、血晶，再按座位顺序。

## 策略提示

- 「血袭／夜行／金血针」对应熟悉的杀／闪／桃。手牌和行动点都很珍贵。
- 角色技能和谋略无视距离；血袭按座位距离计算。眷属让狩猎伤害 +1。
- 一级血脉升级增加血袭伤害，二级降低技能血晶消耗。
- 同盟持续当前与下一轮，不能互相攻击；最终阶段解散。
- 金血针在濒死时会自动使用；回合结束自动弃牌，优先保留治疗、防御和血袭。
- 点击任何人物的「血脉详情」随时查看技能。「血誓档案」内含完整规则、卡牌图鉴与六人技能。
- 数字 1–9 选择手牌，Esc 取消选择。小屏幕可横向滑动敌人区和手牌区。

## 保存进度

游戏自动保存到当前浏览器，回到选人界面点击「继续第 N 轮」。暂停菜单可导出和导入 JSON 存档。私密浏览、禁止本地存储或移动游戏文件后，浏览器可能无法读取原进度；导出存档可跨浏览器迁移。

如果系统不允许直接执行启动脚本，双击同目录 **index.html** 即可，无需修改系统设置。

## 源代码

源码采用 React + TypeScript，规则引擎与 UI 分离。安装 Node.js 22.13+ 后，在源码目录运行 `npm ci`，随后 `npm run dev`。运行 `npm run build:local` 重新生成可直接双击的离线版本；`npm test` 验证规则与完整牌局推进。正式游戏文件已经预编译，无需这些开发步骤。
