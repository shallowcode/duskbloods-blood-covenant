# 黄昏血族 · 血誓牌局

基于 The Duskbloods 网络测试六名角色的非官方单人策略卡牌游戏。一名玩家对战五名 AI，在两次美德筛选中存活，再于三人月血决战中活到最后。

## 下载游玩

在本仓库 **Releases** 下载对应平台 ZIP，完整解压后运行：

- **Windows**：双击 `Start-Game.bat` 或 `启动游戏.bat`。
- **macOS**：双击 `Start-Game.command` 或 `启动游戏.command`。
- 两个平台也都可以直接双击 `index.html`。

游戏使用默认浏览器离线运行，无需安装、Node.js 或服务器。完整玩法见 [玩家说明](README-玩家说明.md)。

## v1.0.0 — 重制

**规则**

- 行动顺序改为每轮按美德排序：领先者先手、落后者压轴（同分按轮换座次）。旧版 0 号座位（玩家）在筛选前结构性吃亏，现已消除；对手座次每局随机。
- 血誓之柱改为「守誓」：立誓 +1，守到自己下回合再 +2；只有美德不高于持誓者的人才能覆写，形成追赶机制。
- 新增「吸血」：每回合首次伤害其他血族 +1 血晶，让交锋有经济回报。
- 血之决斗改为真正的轮流拼血袭；决战中第二条命以半数体力返场，第 9 轮起所有攻击 +1。
- 六名角色按模拟数据重新平衡（见 [VALIDATION.md](VALIDATION.md)）。

**AI**

- 由 if-else 脚本改为「信息集采样 + 局面评估」搜索：AI 看不到你的手牌与牌堆顺序，只在重新洗混的隐藏信息上推演。
- 三档难度：新血（随机失误）、标准（单步推演）、深谋（推演整回合连招）。AI 也会权衡是否出闪，而不是见攻击就闪。
- 「低语」提示：用深谋 AI 为玩家推荐下一步。

**体验**

- AI 出牌横幅、伤害与美德飘字、受击震动、回合 / 阶段 / 筛选过场、合成音效（无音频文件）。
- 选牌后直接点目标出牌；排名中显示筛选线；完整键盘快捷键；新手玩法速览；战绩统计；被淘汰后可观战至终局。
- 手机布局重做：手牌与操作栏固定在底部，战场可滚动，排名和纪事收进「战况」面板。
- v0.2 存档可直接导入（自动迁移）。

**工程**

- 去掉 Next / vinext / Cloudflare / Tailwind / shadcn 等未使用的依赖，改为 Vite + React + 纯 CSS；锁文件中的依赖包从 698 个减到 125 个，样式表从 2.6 MB 降到 35 KB，脚本从 356 KB 降到 267 KB。
- 规则引擎拆分为 `types / data / rules / engine / ai / save` 模块，UI 拆分为独立组件；全部为可读的 TypeScript。
- Vitest 测试：规则单元测试、AI 行为测试（含「不偷看手牌」测试）、存档校验与迁移、120 局完整对局的不变式检查。

## 本地开发

安装 Node.js 22.13+：

```sh
npm ci
npm run dev        # 开发服务器
npm test           # 单元与整局测试
npm run lint       # oxlint（类型感知）
npm run simulate -- 600 normal   # 平衡模拟：英雄 / 座位胜率
npm run build      # 类型检查 + 离线构建 + 包校验，产物在 offline/
npm run release    # 再打包 Windows / macOS ZIP 与 SHA-256，产物在 releases/
```

### 代码结构

```
src/game/   纯函数规则引擎，无 DOM 依赖
  data.ts     角色、卡牌、异象、强敌与全部可调数值 (RULES)
  rules.ts    只读规则查询：距离、合法目标、能否出牌……
  engine.ts   reduceGame(state, action) → state，并产出 fx 效果列表
  ai.ts       信息集采样搜索、局面评估、提示
  save.ts     存档校验与 v1→v2 迁移
src/ui/     React 组件：选人、对局、对话框、效果层、音效、存储
src/styles/ 样式
tests/      Vitest
scripts/    离线打包、包校验、发布、平衡模拟
```

引擎每次动作都会在 `state.fx` 中写出发生了什么（出牌、伤害、美德变化、倒下、筛选……），UI 只消费这份列表来播放动画与音效，规则与表现完全分离。
